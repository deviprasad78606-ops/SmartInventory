# SmartInventory# Smart Inventory Management System

An IoT-based inventory monitoring system using ESP32, Firebase, HTML, CSS and JavaScript.

## Features

- Inventory Tracking
- Low Stock Alert
- Shelf Monitoring
- Automated Replenishment Suggestion

## Hardware

- ESP32-WROOM
- IR Sensors
- Ultrasonic Sensor
- LEDs

## Technologies

- HTML
- CSS
- JavaScript
- Firebase
- Arduino IDE
